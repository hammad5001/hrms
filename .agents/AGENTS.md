# Project-Specific Rules

- **Allowed Modifiable Portals**: Only make changes to the following portals:
  - Recruiter
  - Reception
  - HR
  - Management
  - Training
- **Forbidden Portals/Areas**: Do NOT touch, modify, or interact with any other portal.
- **GitHub Policy**: Do NOT push, upload, or sync any code changes to GitHub.
- **Environment**: All modifications must be done ONLY on localhost (local development files).
